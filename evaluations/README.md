# Evaluations

This folder is an optional home for durable evidence from users, operators, stakeholders, analytics, experiments, support, or other representative evaluation.

Use `../templates/EVALUATION_REPORT_TEMPLATE.md` when a structured record helps.

An AI may organize or summarize human feedback, but it must not fabricate play experience.

Technical brief acceptance and user/product acceptance are separate. When the Project Lead clearly decides to KEEP, CHANGE, DEFER, or reject a tested result, preserve that decision so the Coordinator can synchronize any external project board.

Durable conclusions should eventually be promoted into `PRODUCT.md`, `ROADMAP.md`, or `DECISIONS.md` instead of remaining buried only in old notes.
